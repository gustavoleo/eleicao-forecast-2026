# Brazil state boundaries

Source: IBGE simplified geographic meshes, fetched 2026-10-25.

https://servicodados.ibge.gov.br/api/v3/malhas/paises/BR?intrarregiao=UF&formato=application/vnd.geo+json&qualidade=minima

Documentation: https://servicodados.ibge.gov.br/api/docs/malhas?versao=3

The GeoJSON contains 27 UF features. Overseas is available separately in the UI selector. Colors come exclusively from the conservative local presidential plurality gate; no forecast probabilities or current-leader colors are used. Labels are manually placed for legibility; boundaries are the IBGE data.
